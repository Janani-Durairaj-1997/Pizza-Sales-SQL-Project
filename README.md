# 🍕 Pizza Sales Analysis – SQL Project

## 📌 Project Overview
This project analyses pizza sales data using SQL to evaluate business performance, identify key revenue drivers, and uncover customer ordering trends.

The goal is to transform raw transactional data into meaningful insights that support data-driven decision-making.

---

## 📊 Key Business Questions
- What is the total revenue generated?
- What is the average order value?
- How many orders and pizzas were sold?
- Which pizza categories contribute the most revenue?
- What are the daily and monthly sales trends?
- Which pizzas are top-performing and underperforming?

---

## 🛠️ Tools & Technologies
- SQL (MySQL)
- Data Analysis Techniques
- Aggregations & Grouping
- Window Functions
- Subqueries

---

## 📂 Dataset Description
The dataset contains transactional pizza sales data, including:
- Order details
- Pizza categories
- Sizes
- Pricing

It is used to analyse revenue trends and customer purchasing behaviour.

---

## 📈 Key Insights
- The business generated over **£800K revenue** from **21K+ orders**
- The **Classic category** is the top revenue contributor
- **Large-sized pizzas** are the most preferred
- **Friday and weekends** show peak demand
- Some pizzas (e.g., low-performing items) contribute minimal revenue

---

## 💡 Business Recommendations
- Promote top-performing pizzas to maximise revenue
- Improve or remove low-performing items
- Introduce weekend offers to boost sales further
